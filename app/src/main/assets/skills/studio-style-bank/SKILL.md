# Style bank

## Brand tokens
- Tricid: graphite #16181B, surface #1F2226, line #343A40, green #2BB673, paper #E9ECEF, muted #9AA3AB, red #E5484D (bugs). Font Outfit. Captions Paper on graphite pill, one green word. Logos in `brand/logo-kit/dist`. Disclaimer on end card: "Tricid is an independent project. Not affiliated with Placid."
- BingwaOne: orange #ff632a, navy #0f151c, cream #fff2ed, green #009c4c (M-Pesa feel), brand text orange #b8441a. Font Poppins. Never show Tricid in BingwaOne ads.

## Pick a style by content
| Content | Style |
| --- | --- |
| Story of building/failing (Tricid series) | Creator Motion Graphics (kinetic type, stamps, counters, mockups) + Clean Tech accents |
| Explaining a mechanism to non-devs | Chalk Talk or Pop Info (illustrated) or Inside Out (flat 2D x-ray cutaways) |
| Showing the product working | Software Walkthrough (real capture in device frame, cursor, zoom to fill) |
| Numbers/scoreboard | Data Story |
| Personal/student confession tone | Warm Canvas (talking-head warmth without a face: warm paper ground, serif accent) |
| Agent/seller promos (BingwaOne) | Pop Info / Creator Motion in BingwaOne colours, big stamps, poster conveyors |
| History/before-after of a process | Paper Atlas (cut paper) |
| Hero launch moment | Herk "Infinite" laws: black canvas, light as brand, grid floor, glass cards, chrome type |

## References in this skill
- `references/nafay-styles.md`: full design sheets (look, motion, fonts, size floors, sync rule, sound mapping) for 7 styles.
- Shotcraft faceless styles (clone `windyinwind/hyper-videocraft` or Nafay's faceless-shorts zip): Deep Dive 3D, Night File 3D, Inside Out, Stick Story, Paper Atlas, Tall Tale 3D. Rules shared: a script line is a CUT (picture changes every 1.5-3.5 s while the voice flows); shot list per line with key moments on words; contact sheet every 0.5 s before showing anything.
- Herk house reel numbers: shots 1.1-1.4 s, first cut 0.6-1.0 s, split/full/punch-in layouts, captions in one dark box, colour on 25-45% of chunks.

## Clone a style from a reference (screenshot or video)
1. `studio-reference-analyst` -> sheet + shot data. 2. Write a style sheet: surface (ground/light/texture), type (families, sizes, accent rule), how things appear (arrival style, easing), emphasis devices, numbers treatment, scene-change grammar, pace, sound map. 3. Show one test frame in the new style and check it against the reference before building. 4. Borrow structure and craft, never the other creator's content or branding.
